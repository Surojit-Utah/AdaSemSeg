How the ablations differ

AblationWhat changesCode evidence
Random init vs SimCLR init Random_init\Main.py creates resnet50(pretrained=False); AdaSemSeg\Main.py loads a SimCLR encoder checkpoint via --img_enc_checkpoint. Random_init\Main.py creates image encoder without pretrained weights; AdaSemSeg\Main.py prints “Loaded the SimCLR backbone....” after stripping projection-head weights.
Augmentation ablations SimCLR data loader defines an augmentation set: RandomRotate, RandomHorizontalFlip, GaussianBlur, GaussNoise, RandomResizedCrop, Brightness, Contrast. Contrastive_learning\SimCLR_debug\data\Datasets.py has aug_dict with IDs 1–7.
Baseline-2 architecture No mask encoder, no GP regression; regular encoder-decoder segmentation network. Described in paper; default AdaSemSeg uses image encoder + mask encoder + GP + decoder.

Gaps / issues

  • No dedicated, named script found for “Baseline-2”; it is described in the paper but appears to be represented by an alternate model path, not a standalone ablation runner.
  • Paper describes augmentation-only ablations, but no explicit CLI flag was found to select “None / All / single augmentation” modes.
  • Random_init and Contrastive_learning configs contain hard-coded absolute Linux data paths, so reproduction on Windows requires path editing.
  • Some folders contain cached outputs/logs/checkpoints, but the code itself does not document exact experiment IDs for the paper tables.
