Training details

  • Loss: weighted binary cross-entropy; classwise accumulation; SGD for AdaSemSeg training.
  • Optimizer: AdamW for main few-shot training; Adam for SimCLR.
  • Scheduler: reduce LR by 0.25 after 5 epochs without validation improvement.
  • Augmentations: RandomRotate, RandomHorizontalFlip, GaussianBlur, GaussNoise; SimCLR adds crop/resize, brightness, contrast.
  • SimCLR: 35,648 patches; batch 32; lr 3e-4; wd 1e-4; 10 epochs; tau 0.07.
  • AdaSemSeg: 8,100 / 7,664 / 8,206 patches (Penobscot / F3 / Parihaka); lr 5e-5; wd 1e-3; source-data leave-one-out.

Gaps / reproducibility issues

  • Config paths are hardcoded to /home/sci/surojit/Exxon_Research/Data/... in several configs; local data not bundled.
  • Exact train/val/test JSON splits are referenced but not present in repo.
  • Paper cites Fig./Table 4/9-12 style results, but code organization doesn’t clearly expose a one-to-one script per result.
  • ProtoSemSeg settings are delegated to prior work; local repo lacks a self-contained paper-specific config.
  • Some folders include duplicate evaluation variants (Evaluation_sampling, Evaluation_nearest_slice) without a top-level launcher documenting which table/figure they generate.
