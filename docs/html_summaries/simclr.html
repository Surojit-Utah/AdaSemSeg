SimCLR Pretraining Reproducibility Summary

Role in the repo

SimCLR is not a competing segmentation method. It is the self-supervised pretraining technique used to initialize the ResNet50 image encoder of AdaSemSeg, Baseline-2, and ProtoSemSeg.

Paper context

SimCLR is trained on unlabeled seismic patches and only the backbone weights (not the projection head) are reused for downstream segmentation methods. The paper reports top-1 accuracy of 93.75% and top-5 accuracy of 98.44% for the trained encoder. An ablation compares random encoder initialization vs SimCLR initialization on the Parihaka dataset under 1-shot and 5-shot settings.

Training details from paper

  • Data: 35,648 patches extracted from the F3, Penobscot, and Parihaka datasets (all unlabeled seismic slices).
  • Augmentations for positive/negative pairs:
    • Random rotation in [-20°, 20°]
    • Random horizontal flip
    • Gaussian blur with σ ∈ [0.1, 2.0]
    • Gaussian noise with variance ∈ [1e-4, 5e-2]
    • Random crop with resize
    • Brightness jitter ∈ [0.5, 1.5]
    • Contrast jitter ∈ [0.0, 2.0]
  • Model: ResNet50 backbone + 2-layer projection head (output dim = 128).
  • Loss: InfoNCE / NT-Xent with temperature τ = 0.07.
  • Optimizer: Adam, learning rate = 3e-4, weight decay = 1e-4.
  • Batch size: 32.
  • Epochs: 10.
  • Reported accuracy: top-1 = 93.75%, top-5 = 98.44%.

Important discrepancy

The paper reports SimCLR top-1 = 93.75% and top-5 = 98.44%. Run_1 matches these values (epoch 8 top-1 = 93.75%; epoch 9 top-1 = 98.4375% ≈ 98.44%). However, the downstream runfiles (Baseline/runfile.txt, Baseline/Evaluation/runfile.txt) point to Run_2 for the image-encoder initialization. Please confirm which run was actually used for the final paper results before sharing weights.

How it works

  • run.py builds SimCLR_dataset(...) from seismic volumes, then instantiates ResNetSimCLR(resnet18|resnet50, out_dim=128).
  • simclr.py implements InfoNCE loss over two views, uses automatic mixed precision (AMP), logs to TensorBoard, and saves checkpoints (checkpoint_####.pth.tar).
  • data/Datasets.py uses weighted sampling over classes and applies rotation, flip, blur, noise, and RandomResizedCrop; returns two stacked augmented views.

Checkpoint loading into downstream methods

AdaSemSeg, Baseline, and Proto_FSS load SimCLR checkpoints with the following pattern:

checkpoint_dict = torch.load(...)
trained_model_param = checkpoint_dict['state_dict']
# strip last 4 projection-head parameters
# remove 'backbone.' prefix
resnet.load_state_dict(..., strict=True)

Only the ResNet backbone is reused; the SimCLR projection head is discarded.

Variant: SimCLR_init_dataset_v1

This folder contains downstream training/evaluation code rather than SimCLR pretraining itself. It includes multiple dataset versions (data/versions/Datasets_v1.py, Datasets_v2.py) and several experiment subfolders. Its config/local_config.py defaults to F3 inline/crossline with different patch overlaps than the main SimCLR config.

Gaps / reproducibility issues

  • Code/docs mismatch: README.md examples target CIFAR-10/STL-10, but this project uses seismic patches via SimCLR_dataset.
  • Hard-coded Linux data paths in config/local_config.py.
  • env.yml and requirements.txt are outdated (PyTorch 1.4, Python 3.7, CUDA 10.1; includes nvidia-apex even though the AMP path is used).
  • Checkpoint loading assumes exact key layout and strips the final 4 parameters; fragile if the model changes.
  • No single script trains SimCLR for each of the three datasets independently; dataset selection is via local_config.py class list.
