3. Common reproducibility gaps

High priority

  • Hard-coded Linux paths: configs across all folders point to /home/sci/surojit/Exxon_Research/Data/.... Reproduction on Windows or other machines requires manual path editing.
  • Missing evaluation scripts: AdaSemSeg Main.py has --test and --test_num_support arguments that are unused; DGP_Evaluator is referenced but not found.
  • Interactive evaluation: Proto_FSS and Baseline evaluation scripts prompt for source_class via input(), which prevents batch/automated reproduction.
  • Dataset splits not bundled: train/val/test JSON split files are referenced but not included in the repository.

Medium priority

  • Outdated dependencies: SimCLR env.yml/requirements.txt specify PyTorch 1.4, Python 3.7, CUDA 10.1, and nvidia-apex.
  • Fragile checkpoint loading: SimCLR checkpoint loading strips the last 4 projection-head parameters by index and removes a backbone. prefix; brittle to model changes.
  • No unified top-level launcher: each method has its own Main.py with different argument conventions; no single script reproduces all paper tables.
  • Augmentation ablations lack CLI flags: paper studies single-augmentation and no-augmentation modes, but no flag selects these modes.
  • Baseline-2 not clearly demarcated: architecture ablation is described in the paper but implemented as alternate encoder choice, not a standalone runner.

Low priority

  • README files are minimal or target natural-image datasets (SimCLR).
  • Log/checkpoint naming conventions vary across folders.
  • Some cached outputs/logs are present but not documented.

4. Recommended next steps

  1. Unify data configuration: create a top-level config/datasets.yaml with relative paths and dataset splits; make all methods read from it.
  2. Implement missing evaluation paths: add test/eval modes to AdaSemSeg Main.py and provide DGP_Evaluator; remove interactive prompts from Proto_FSS/Baseline evaluation.
  3. Create reproduction scripts: one script per paper table/figure (e.g., reproduce_table1.sh, reproduce_table2.sh, etc.).
  4. Modernize dependencies: update requirements.txt and environment.yml to recent PyTorch/Python versions; remove obsolete nvidia-apex.
  5. Robust checkpoint loading: load SimCLR backbone by key matching instead of stripping fixed parameter counts.
  6. Documentation: expand README with architecture diagrams, method descriptions, result tables, and step-by-step reproduction instructions; copy relevant figures from Paper/images/.
  7. Bundle dataset splits: include train/val/test JSON files or a script to generate them from the raw public datasets.
