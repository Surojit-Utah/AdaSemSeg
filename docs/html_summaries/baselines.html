Baselines & Transfer Learning Reproducibility Summary

Paper mapping

  • Baseline-1 = AdaSemSeg trained only on target data. Discussed in §5.1.3 and §5.2.2.
  • Baseline-2 = U-Net/ResNet-UNet segmentation network trained on target data. Discussed in §5.1.3, §5.2.2, and §5.2.6 (architecture ablation).
  • Transfer learning = Baseline-2 pretrained on source datasets, then fine-tuned on target support set. Discussed in §5.1.3 and §5.2.3.

Implementation notes

  • Baseline-1 and Baseline-2 share the same Main.py; the model is chosen via --img_enc_type (ResNet50/UNet). Baseline-2 is the regular segmentation network; Baseline-1 is the same code path trained only on target data.
  • ResNet-UNet uses a ResNet50 encoder and U-Net-style decoder with class-specific heads for Parihaka, Penobscot, and F3.
  • UNet baseline is the simpler encoder-decoder.
  • Training uses weighted cross-entropy, AdamW, ReduceLROnPlateau, 20 epochs, batch size 10 (train) / 40 (validation).
  • Transfer learning trains on source datasets first, then fine-tunes on target slices using --train_indices and --checkpoint.
  • Evaluation loads checkpoints and computes IoU, pixel accuracy, mean IoU, and F1 via runningScore.

Config details

  • Baseline/config/local_config.py: target-only training presets; default classes are Parihaka inline/crossline.
  • Baseline/Transfer_learning/config/local_config.py: training on source datasets; defaults to F3 inline/crossline; target slices selected by --train_indices.
  • Baseline/Evaluation/config/local_config.py: evaluation over all datasets; writes results under results/.
  • Baseline/runfile.txt contains an example command.

Gaps / reproducibility issues

  • Hard-coded Linux data paths in configs (/home/sci/.../Data/Facies/...) reduce portability.
  • Baseline/Main.py has no explicit CLI for target dataset selection; dataset choice comes from config.
  • Transfer_learning/Main.py requires manual --train_indices and checkpoint wiring.
  • Evaluation prompts interactively for source_class, which complicates automation.
  • Some names are confusing: Baseline-2 is described as the “regular segmentation network” but implemented as ResNet-UNet / UNet depending on --img_enc_type.
