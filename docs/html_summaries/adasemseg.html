AdaSemSeg Reproducibility Summary

Method overview

AdaSemSeg turns multi-class seismic facies segmentation into multiple binary tasks with one shared model per dataset. It uses a ResNet50 image encoder, a U-Net-like mask encoder, Gaussian process (GP) regression in latent space, and a decoder that fuses GP outputs with skip connections.

Paper notes

  • Section 4: multi-class labels are decomposed into class-wise binary masks; the image encoder, mask encoder, and decoder are shared across classes.
  • Meta-training uses only source datasets; the target dataset is never used to fine-tune parameters.
  • Appendix: image encoder = ResNet50; augmentations = RandomRotate, RandomHorizontalFlip, GaussianBlur, GaussNoise.
  • Training config in paper: AdamW optimizer, learning rate 5e-5, weight decay 1e-3, LR decay ×0.25 after 5 epochs of no validation improvement, 10 epochs total.

How data and tasks are built

The dataset code loads .npy seismic volumes and JSON split files. For each query patch, support patches are sampled from nearby valid slices (training) or from training slices (validation). Multi-class labels are converted into class-specific binary masks so that each facies is treated as an independent binary segmentation task during training.

Reproduction commands

# 1-shot training example
python Main.py --train --run_id 1 --shots 1 --device cuda:0 --seed 0

# 5-shot training example
python Main.py --train --run_id 1 --shots 5 --device cuda:0 --seed 0

Switch source/target settings by editing config/local_config.py classes (F3, Parihaka, Penobscot). Checkpoints and logs are written under logs/.

Reproducibility gaps / issues

  • No implemented test/eval branch in Main.py; --test and --test_num_support arguments are unused.
  • DGP_Evaluator is referenced but not found in the repo.
  • Config uses relative dataset paths; dataset download and preprocessing steps are not documented in code.
  • local_config.py is hardcoded to Parihaka classes by default.
  • Pretrained SimCLR encoder checkpoint path is external and not included.
